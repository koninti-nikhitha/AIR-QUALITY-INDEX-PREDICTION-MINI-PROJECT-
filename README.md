# 🌍 Air Quality Monitoring & AQI Prediction System

## 📌 Project Description

The **Air Quality Monitoring & AQI Prediction System** is a data-driven application designed to monitor air pollution and predict the **Air Quality Index (AQI)** based on major air pollutants such as PM2.5, PM10, NO₂, SO₂, CO, and O₃.

The system provides the predicted AQI along with its pollution category and gives personalized health recommendations for different groups such as children, adults, pregnant women, elderly people, asthma patients, and heart patients.

It also provides a **7-day AQI forecast** and **yearly AQI trend analysis**, helping users understand future air-quality conditions and long-term pollution patterns.

## 🎯 Objectives

* Monitor important air pollutants.
* Predict the AQI based on pollutant concentrations.
* Classify air quality into pollution categories.
* Provide health recommendations based on AQI levels.
* Forecast AQI for the next 7 days.
* Analyze yearly AQI trends.
* Provide an easy-to-use dashboard for users.

## ✨ Key Features

* 📊 **AQI Prediction**
* 🌫️ **Pollutant Monitoring**
* 🚦 **AQI Category Classification**
* ❤️ **Health Recommendations**
* 🔮 **7-Day AQI Forecast**
* 📈 **Yearly AQI Trend**
* 🏙️ **City-Based AQI Monitoring**
* 📥 **Forecast Download Option**
* 🖥️ **Interactive Streamlit Dashboard**

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Machine Learning
* Time-Series Forecasting
* Matplotlib / Plotly

## 📊 Dashboard

The dashboard displays air-quality data for the selected city, predicted AQI, pollution level, and health recommendations. For example, the system can display pollutant readings for Delhi and classify a predicted AQI of 178.33 as **Moderately Polluted**.

## 👥 Health Recommendations

The system provides recommendations for different user groups, including:

* Babies
* Children
* Adults
* Pregnant Women
* Heart Patients
* Asthma Patients
* Elderly People

These recommendations help users take appropriate precautions according to air-quality conditions.

## 🚀 Future Enhancements

* Real-time sensor integration
* More city and station coverage
* Mobile application
* Automated pollution alerts
* Multilingual support
* Improved long-term forecasting
* Integration with IoT-based air-quality sensors

## 📌 Conclusion

The **Air Quality Monitoring & AQI Prediction System** combines air-quality monitoring, AQI prediction, forecasting, and health recommendations into a single interactive platform. It can help users understand current and future pollution levels and take suitable precautions to reduce health risks.
